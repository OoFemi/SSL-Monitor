FOB SSL Monitor v1.0.2 Operations Manual

This manual details the setup, operation, and maintenance guidelines for tracking core infrastructure endpoints, verifying uptime telemetry, and managing automated or manual SSL certificate workflows across FOB IT architecture.

1. Adding & Managing Endpoints

Targets are registered via the Admin panel. Each target string requires an active protocol definition (https:// or http://). Tags and grouping categories help split traffic metrics between production nodes, microservices, and client portals.

2. SSL Expiry Thresholds

The monitoring daemon checks certificate validity chains routinely. When an active certificate falls below a 14-day remaining window, the dashboard highlights the entry in warning red and injects a dynamic direct renewal link action button.

3. Diagnostic Logging & Alerts

System runtime events, connectivity dropouts, and failed handshake attempts are piped directly into the persistent ring-buffer. Use the Log viewer terminal interface to tail live service outputs or debug intermittent socket connection losses.

4. Refresh Cycles

Automatic background evaluation sweeps occur continuously. Operators can bypass the background schedule at any time by triggering the manual Refresh Now button located in the primary control header.
